# Chemical-exposomebase

**Project Overview**

This project involves the creation of a comprehensive exposome knowledge base that links genetic data, environmental toxicants, and information about population-specific genetic variants. The goal is to provide a dynamic, user-friendly platform for exploring the intricate relationships between toxic chemicals, genetic variants, and their potential role in complex diseases. The project incorporates SQLite database creation which helps effective querying, collection, and visualisation of data through a Shiny interface.

**Source of the data**

1. Ensembl 1000 Genomes Project
   - Data Type: Genomic variants (VCF files)
   Version: Latest available release (e.g., GRCh38, 1000 Genomes Project Phase 3)
   Details: This dataset provides high-resolution genetic variation data across diverse human populations, including SNPs, indels, and structural variants, which is crucial for population genetics and variant analysis.

Link: Ensembl 1000 Genomes Project

Toxin and Toxin Target Database (T3DB)

Data Type: Chemical data and associated toxicological information

Version: T3DB v2.0

Details: This database provides curated information on over 3,600 chemicals and their associated biological targets, mechanisms of action, and toxicity profiles. It is used to link environmental toxicants with genetic susceptibility in toxicogenomics studies.

Link: T3DB
